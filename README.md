# `.github` — Waffle-Commons organization profile

This repository hosts the **public organization profile** for [github.com/waffle-commons](https://github.com/waffle-commons) and the shared assets (logo, dependency graph image) referenced by the rest of the ecosystem.

> 👉 **The canonical landing page is [`profile/README.md`](profile/README.md).** That's the file GitHub renders on the organization profile.

## Contents

| Path | Purpose |
| :--- | :--- |
